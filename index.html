BetterLyrics

BetterLyrics 是一款优雅且高度自定义的歌词可视化与全能音乐播放应用，基于 WinUI3 / Win2D 构建。

C# WinUI 3 Windows App SDK Win2D MVVM

特性概览

  • Win2D 自定义渲染，高帧率且低系统开销
  • 流体背景、3D 歌词、粒子特效及多视窗模式
  • 深度兼容本地媒体及主流流媒体（Spotify / Apple Music 等）
  • 多格式歌词解析引擎，支持离线机器翻译
